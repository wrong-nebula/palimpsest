## 2. Coordinate, Grid & Angle Conventions (Canonical)

1. **Grid Layout (`shape = (ny, nx)`)**:
   - Right-handed Cartesian raster in `EPSG:6676` meters.
   - `col ∈ [0, nx - 1]` increases **Eastward** (`+X`): `x(col) = x0 + (col + 0.5) * dx`.
   - `row ∈ [0, ny - 1]` increases **Northward** (`+Y`): `y(row) = y0 + (row + 0.5) * dx`.
   - `(x0, y0)` is the **South-West (SW) outer corner** of cell `(0, 0)` in `EPSG:6676`.
   - Default resolution: `dx = 0.5` m (`0.25 m²` per cell).
   - With this convention, `grad_y, grad_x = np.gradient(dem, dx)` satisfies `grad_x = ∂z/∂x` (East) and `grad_y = ∂z/∂y` (North) without sign flips.
2. **Azimuth / Flow Angle Convention**:
   - Standard mathematical polar angle in radians `θ ∈ [0, 2π)` (or `(-π, π]`) measured **counter-clockwise from +East (`+X`)**: `θ = atan2(v_y, v_x)`.
   - Downslope direction is `-∇z = (-∂z/∂x, -∂z/∂y)`. Thus a plane `z = -x - y` slopes down toward `(+1, +1)` with flow azimuth `θ = +π/4` (`45°`).
   - Geographic bearing (CW from North) for human display is `bearing_deg = (90.0 - degrees(θ)) % 360.0`.
3. **UV Texture Alignment (WebGPU / Aerial Draping)**:
   - Cropped aerial textures (`packs/textures/<candidate_id>/<layer>.png|jpg`) are standard top-down (North-up) raster images.
   - For grid point `(rel_x, rel_y)` in `[0, nx * dx] × [0, ny * dx]`, texture coordinates are:
     `u = rel_x / (nx * dx)`, `v = 1.0 - rel_y / (ny * dx)` (or flipped if WebGPU texture sampling uses top-left `v=0` at North: `v = 1.0 - rel_y / (ny * dx)`).

## 4. Binary Tile Pack Format (`data/output/packs/<candidate_id>.bin`)

All integers and floats are **little-endian**.

### 4.1 64-Byte Header

| Byte Offset | Type | Field | Description |
|---|---|---|---|
| `0..4` | `char[4]` | `magic` | Exact ASCII `b"PLMP"` |
| `4..8` | `uint32` | `version` | `1` |
| `8..12` | `uint32` | `nx` | Grid columns (`400` for 200 m @ 0.5 m) |
| `12..16` | `uint32` | `ny` | Grid rows (`400` for 200 m @ 0.5 m) |
| `16..24` | `float64` | `x0` | Cutout SW corner X (`EPSG:6676`) |
| `24..32` | `float64` | `y0` | Cutout SW corner Y (`EPSG:6676`) |
| `32..36` | `float32` | `dx` | Grid spacing in meters (`0.5`) |
| `36..40` | `uint32` | `n_layers` | `10` |
| `40..44` | `uint32` | `n_canopy_pts` | Number of packed 3D points (`<= 150000`) |
| `44..48` | `float32` | `z_min` | Minimum `z_gnd` in cutout (m) |
| `48..52` | `float32` | `z_max` | Maximum `z_gnd` in cutout (m) |
| `52..64` | `uint8[12]` | `reserved` | Zero-padded |

### 4.2 Planar Grid Layers (`float32`, `10 * nx * ny * 4` bytes)

Stored sequentially as `10` contiguous planes of shape `(ny, nx)`, C-contiguous (`row * nx + col`, `row=0` South, `col=0` West):

0. `z_gnd`: bare-earth DTM elevation (m)
1. `chm`: canopy height model `z_first - z_gnd` (m)
2. `rho_gnd`: ground return density (`pts/m²`)
3. `rrim_r`: Chiba RRIM Red channel normalized `[0.0, 1.0]`
4. `rrim_g`: Chiba RRIM Green channel normalized `[0.0, 1.0]`
5. `rrim_b`: Chiba RRIM Blue channel normalized `[0.0, 1.0]`
6. `svf`: Sky-View Factor `[0.0, 1.0]`
7. `lrm`: Hesse Local Relief Model (m)
8. `openness_diff`: differential openness $I_{10} = (\Phi_{10} - \Psi_{10})/2$ (rad)
9. `flow_violation`: drainage violation score `[0.0, 1.0]`

### 4.3 Packed Canopy Point Cloud (`float32`, `n_canopy_pts * 4 * 4` bytes)

Immediately follows byte offset `64 + 10 * nx * ny * 4`. Each point is 4 × `float32`:
- `rel_x`: `x - x0` in `[0, nx * dx]` meters
- `rel_y`: `y - y0` in `[0, ny * dx]` meters
- `z_abs`: absolute elevation in meters
- `hag`: height above `z_gnd` (`z_abs - z_gnd(x, y)`) in meters

## 6. `data/output/palimpsest_waypoints.gpx` Schema

Standard **GPX 1.1** (`xmlns="http://www.topografix.com/GPX/1/1"`), containing `<wpt lat="..." lon="...">` for every surviving candidate (`Class A`, `Class B`, `Class C`), with:
- `<ele>` = bare-earth elevation (m)
- `<name>` = `candidate_id` (`PLMP-0001`)
- `<cmt>` = `[Class A] terrace | wall=2.4m scarp=38.5° rho=1.65/m2`
- `<sym>` = `Flag, Red` (Class A), `Flag, Blue` (Class B), `Flag, Green` (Class C)
- `<type>` = `temporal_class`
